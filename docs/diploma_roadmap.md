# Дорожная карта дипломного проекта

Тема ВКР: «Разработка программного обеспечения для интеллектуальной обработки и
автоматизированного перевода документов в формат Markdown».

## Текущее состояние

Проект уже содержит рабочую основу программной системы:

- CLI для одиночной и пакетной конвертации документов.
- FastAPI-сервер для вызова конвертации через API.
- Конвейер обработки документов: `providers -> builders -> processors -> renderers`.
- Рендер результата в Markdown, HTML, JSON и chunks.
- Модуль автоматизированного перевода Markdown через LLM-сервис.
- Поддержку локального LLM-сервиса Ollama и OpenAI-совместимых сервисов.

Проверенный демо-запуск:

```powershell
.\.venv\Scripts\python.exe convert_single.py 2601.00100v1.pdf `
  --output_format markdown `
  --output_dir out `
  --page_range 0 `
  --disable_multiprocessing `
  --disable_image_extraction `
  --disable_ocr
```

Результат сохраняется в:

```text
out\2601.00100v1\2601.00100v1.md
```

## Как это описывать в дипломе

Разработанная система автоматизирует процесс преобразования документов в
структурированный Markdown. На первом этапе документ загружается через provider,
после чего строится представление страниц, строк и блоков. Далее набор
процессоров уточняет структуру документа, исправляет порядок чтения и обрабатывает
специальные элементы. После этого renderer формирует Markdown, который может быть
передан в модуль автоматизированного перевода.

Практическая ценность системы заключается в сокращении ручных трудозатрат,
повышении повторяемости результата и сохранении структуры документа при
подготовке Markdown-материалов.
